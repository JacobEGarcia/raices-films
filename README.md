# Raíces Films

Two procedural animated films. Every frame is drawn by code - Python, PIL and
numpy; no cameras, no stock footage. A monarch butterfly leaves a Chicago
rooftop and follows the lake three thousand miles south to the oyamel forests
of Michoacán.

**Screening room: https://jacobegarcia.github.io/raices-films/**

## The films

## Source

`rf.py` / `short.py` / `score.py` are the RAICES pipeline: the short itself
(`short.py`), the shared drawing library (`rf.py`) and the score cues
(`score.py`). Fonts: Cinzel and Cormorant (Google Fonts, OFL).
